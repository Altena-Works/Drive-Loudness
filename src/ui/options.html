Google連携と保存データ

Googleアカウント連携

Driveの動画を読み取る

Google Drive全体の読み取り権限を使用します。動画の情報と必要な音声区間だけを取得し、ファイルの作成・変更・削除は行いません。

Googleのログイン・同意は、ご自身で操作してください。

解除すると、この拡張が保持するトークンと測定結果を消去します。Google側のアプリ許可の撤回はGoogleアカウントの設定から行えます。

測定結果

このブラウザ内に保存

測定結果はこのブラウザ内だけに保存します。動画本体や音声、認証トークンは保存しません。動画が更新されると再解析します。

最大5000件・5MiBまで保存し、上限では古い結果から整理します。

使い方

動画を開くだけで自動補正

  1. 「Googleに接続」から読み取りを許可します。
  2. DriveでMP4動画を開くと、自動で解析して補正を準備します。
  3. Driveの再生ボタンで視聴します。適用した補正量だけを動画上に約3秒表示します。
  4. 補正の停止・再開は、拡張ボタンから操作できます。聞く音量は端末側で調整してください。

動画を切り替えると、次の動画も同じ基準で自動補正します。

冒頭と全体の3秒区間を最大16地点測定します。48秒以下では音声区間を連続して測定します。取得量64MiB・256要求・60秒の上限に達した場合は終了します。

平均音量に加え、冒頭や大きい区間の短時間音量を考慮して固定補正します。短時間音量の許容差は目標から6 LUを初期値としています。推定精度・未測定部分・音割れは保証できません。
